# 🛡️ FakeFact - Your Ultimate Cyber Safety AI

FakeFact is a Python desktop application that uses Gemini AI to help users analyze suspicious digital content and learn safer online practices. It brings several cyber-safety checks together in one simple interface.

## 🚀 Features

- 📱 **SMS Checker** — analyze suspicious SMS messages for spam or phishing signals.
- 📰 **News Fact Checker** — get an AI-assisted assessment of news content.
- 📧 **Email Analyzer** — inspect an email address for potentially suspicious patterns.
- 🔗 **URL Checker** — analyze links for phishing or unsafe indicators.
- 🖼️ **Deepfake Image Detection** — inspect uploaded images for possible manipulation.
- 🎬 **Video Frame Analysis** — extract and analyze a video frame for deepfake indicators.
- 🤖 **AI Cyber Assistant** — ask cyber-safety questions and receive quick guidance.
- 📜 **Safety Resources** — access cybercrime helpline information and digital-safety guidance.

## 🛠️ Tech Stack

- **Language:** Python 3.9+
- **UI:** Tkinter, ttkbootstrap
- **AI:** Google Gemini
- **Media Processing:** OpenCV, Pillow
- **Text Tools:** language-tool-python

## 📦 Installation

```bash
git clone https://github.com/Neetesh1541/Fakefact.git
cd Fakefact
pip install -r requirements.txt
```

Configure the required Gemini API credentials as expected by the application, then run the project's main Python entry point.

## 🔐 Safety Note

FakeFact is an assistive analysis tool, not a forensic or legal verification system. AI results should be treated as indicators and independently verified before taking important action.
